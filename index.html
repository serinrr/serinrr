方法三：控制台脚本

步骤1：打开控制台

  1. 在预览页面按 F12 打开开发者工具
  2. 切换到 "Console" 标签
  3. 粘贴并执行下面的代码：
(function() { var buttons = document.querySelectorAll('button, [role="button"]'); for (var i = 0; i < buttons.length; i++) { var text = (buttons[i].textContent || buttons[i].innerText || '').trim(); if (text.includes('预览') || text.includes('进入') || text.includes('Preview') || text.includes('Enter')) { buttons[i].click(); console.log('✅ 已自动进入小程序！'); return; } } console.log('❌ 未找到按钮'); })();
⚠️ 注意：
  • 书签脚本只能在预览页面上使用
  • 确保在页面完全加载后点击书签
  • 如果自动点击失败，可能需要手动点击

故障排查

如果脚本不起作用：

  1. 检查页面是否加载完成：等待几秒后再点击书签
  2. 检查按钮文本：可能需要修改脚本中的关键词
  3. 查看控制台：按F12查看是否有错误信息
  4. 手动点击：最可靠的方法还是手动点击按钮
